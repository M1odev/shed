Shed is a social practice journal for musicians.

Feature List
 -- Users can track practice sessions live, or manually add details for sessions they've already completed
 
 -- Practice Sessions can be broken into a series of items for more detail. 
    For example, 15 minutes of warm up, 10 minutes of scales, 20 minutes of ___ repertoire etc.
    
 -- Users can view other's practice sessions on the homepage feed
 
 -- The previous sessions page provides a way for musicians to journal their practice and track improvement


Stack
 -- React (with Vite)
 -- Supabase 
 -- Vercel 
 -- React Router
